# okf

Mallika's source files. The pipeline reads everything here and invents nothing.

| Path | Purpose |
|---|---|
| `profile.yaml` | Name, contact, photo, signature, file prefix |
| `project_catalog.yaml` | Projects and metrics (source of truth) |
| `project_catalog_condensed.yaml` | Generated copy without bullets |
| `base_files/english/resume.md`, `base_files/german/resume_de.md` | Base resumes in English and German |
| `templates/Resume_latex.yaml`, `Resume_regular.yaml` (English), `Resume_latex_de.yaml`, `Resume_regular_de.yaml` (German) | Example resumes for the two types |
| `templates/Cover_Letter_en.yaml`, `Cover_Letter_de.yaml` | Cover letter templates with placeholders |
| `skill_mappings.yaml`, `project_mappings.yaml` | Obsidian sync name normalization |
| `Photo.jpg` | Headshot for the LaTeX resume |
| `Mallika_Mujgule_CV.pdf`, `Portfolio link - Google Docs.pdf`, `Forward…pdf` | Original source documents |
